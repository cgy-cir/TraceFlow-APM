# TraceFlow 数据库迁移 V2：统一毫秒时间戳

## 1. 目标

V2 将所有业务时间列从无时区信息的 `DATETIME(3)` 转换为 `BIGINT UNSIGNED`，统一保存 Unix Epoch 毫秒。

统一约定：

- SDK、服务端、数据库和 API 都传递 13 位毫秒时间戳。
- 后端不把时间戳转换成 `LocalDateTime`。
- 前端仅在展示层通过 `new Date(timestamp)` 按用户本地时区格式化。
- 排序、筛选和数据保留任务直接使用数值时间戳。

## 2. 迁移字段

- `users.created_at`、`users.updated_at`
- `applications.created_at`、`applications.updated_at`
- `issues.first_seen_at`、`issues.last_seen_at`、`issues.created_at`、`issues.updated_at`
- `events.occurred_at`、`events.received_at`、`events.created_at`

迁移脚本使用 `TIMESTAMPDIFF` 将 V1 中按 UTC 保存的 `DATETIME(3)` 转成毫秒，原有时间索引会在字段转换后以相同顺序重建。

## 3. 示例

接口存储与返回：

```json
{
  "occurredAt": 1790589038273
}
```

浏览器展示：

```ts
new Intl.DateTimeFormat('zh-CN', {
  dateStyle: 'short',
  timeStyle: 'medium',
}).format(new Date(1790589038273))
```

时间戳表示绝对时刻，不携带“北京时间”或“UTC 时间”的歧义；时区只属于展示层。
