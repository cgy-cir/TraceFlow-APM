# TraceFlow 数据库迁移 V5 说明

V5 将 `performance_metric_buckets.metric_min` 和 `metric_max` 从 `DECIMAL(16,4)` 扩展为
`DECIMAL(24,4)`。

原因是 V4 同时支持 `bytes` 指标，而性能事件协议允许资源大小达到 JavaScript
`Number.MAX_SAFE_INTEGER`。原精度最多只能保存 12 位整数，无法覆盖协议范围。

V4 已经在开发数据库和 Git 历史中执行，按照 Flyway 只向前迁移原则不得修改其校验和，
因此使用 V5 修正。该迁移只扩大数值范围，不改变既有数据和 API 语义。
